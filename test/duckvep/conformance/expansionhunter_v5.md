# ExpansionHunter v5 single-repeat preparation

The supported VCF contract is the [ExpansionHunter v5.0.0 output specification](https://github.com/Illumina/ExpansionHunter/blob/v5.0.0/docs/06_OutputVcfFiles.md) and its [public example VCF](https://github.com/Illumina/ExpansionHunter/blob/v5.0.0/example/output/repeats.vcf) with [reference FASTA](https://github.com/Illumina/ExpansionHunter/blob/v5.0.0/example/input/reference.fa). Pinned fixture SHA-256 values are `1a074981f03589a5a4ff4de6cc27d6792be644699a66778335f47193b72ca8bd` and `c912c2aa0987117d8fa612c0748c44cba570da97189c2b8a9929381086f5d7ea`. The v5 example uses `REPCN`/`REPCI` (the documentation's displayed VCF uses `CN`/`CI`); this preparer supports the example's explicit FORMAT schema.

`rduckvep_prepare_expansionhunter()` accepts a selected ALT index, INFO and FORMAT/sample strings, the padding REF base, and the **literal** reference repeat interval from POS+1 through END. `INFO/REF` is a repeat count, not VCF REF. It checks `REF * nchar(RU) == RL == nchar(literal)` and the ordered literal bases before offering components to `duckvep_repeat_alleles`. Only a called `<STRn>` allele with matching REPCN, point REPCI, and SPANNING support becomes an exact alternate. Other calls retain the source and a stable invalid, incomplete, or summary reason; a summary does not manufacture bases. This is a single pure repeat unit, not a parser for complex interruption or multi-motif loci.

The published chr1:2005 example reports `RL=1` while its POS+1..END reference interval is `CAG` (3 bp). Both raw alleles are therefore `reference_mismatch`. A controlled `RL=3` witness on that real sequence produces reference CAG and alternates CAGCAG and CAG repeated ten times. `Rscript test/duckvep/conformance/expansionhunter_v5_differential.R` independently compares the FASTA-derived literal oracle and selected ALT copy counts with the native repeat fact on an immutable copied extension. The raw failures are part of the differential; the controlled witness is not claimed as an unmodified caller output.
